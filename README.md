# IZBFACE

Репозиторий проекта «Избушка» с кодом для лица, голосового управления и сенсоров.

## Структура

- [`Face`](./Face) - основной проект лица и голосовой логики.
- [`ArduinoSensor`](./ArduinoSensor) - чтение температуры и влажности с Arduino.
- [`STM32Code`](./STM32Code) - ранняя версия прошивки STM32 (CubeMX + Keil, неактуально).
- [`STM32Arduino`](./STM32Arduino) - актуальная версия кода STM32.

## Голосовой ассистент (`Face/audio.py`)

Файл [`Face/audio.py`](./Face/audio.py) реализует голосового ассистента:

- слушает микрофон через `speech_recognition`;
- озвучивает ответы через `pyttsx3`;
- обрабатывает голосовые команды для выражений лица;
- умеет отвечать через OpenAI и, при возможности, через Wikipedia.

Для работы ассистента нужно:

1. Установить зависимости из `Face/requirements.txt`.
2. Указать API-ключ OpenAI в `Face/audio.py`.
3. Проверить корректный `device_index` микрофона в `VoiceProcessor`.
